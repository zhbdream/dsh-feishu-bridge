# 飞书应用权限清单（模板）

在飞书开发者后台勾选权限后，可按本表自检。**不要**把 App Secret、真实 App ID、成员姓名写入公开仓库。

## 事件

| 项 | 建议值 |
|----|--------|
| 订阅方式 | **长连接**（本机无需公网） |
| 订阅事件 | `im.message.receive_v1` |

## 最小权限

| 权限名称（后台原文） | 权限标识 | 用途 |
|----------------------|----------|------|
| 获取与发送单聊、群组消息 | `im:message` | 收发消息 |
| 读取用户发给机器人的单聊消息 | `im:message.p2p_msg:readonly` | 读单聊入站 |
| 以应用的身份发消息 | `im:message:send_as_bot` | 机器人回帖 |

## 发布检查

1. 启用机器人能力，创建版本并发布
2. 把自己加入可用成员
3. 本机配置 App ID / App Secret / `allowOpenIds`（见 [local-config.md](./local-config.md)）
4. 飞书中搜索机器人并发一条纯文本验证

## 备注

- MVP 仅单聊文本；群聊相关可留到后续版本
- 权限变更后需重新创建并发布应用版本
